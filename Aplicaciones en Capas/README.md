# Aplicaciones en Capas

Aplicaciones de escritorio en C# separadas en capas, donde cada capa es un
proyecto propio dentro de la misma solución: vista, controladora, modelo y
entidades. La vista no habla nunca con el modelo de forma directa, siempre pasa
por la controladora.

Cada carpeta es un proyecto independiente con su propia documentación.

## Proyectos

Todavía no hay proyectos publicados acá. Se van sumando a medida que se
revisan.
