# Layered Applications

C# desktop applications split into layers, where each layer is its own project
inside the same solution: view, controller, model, and entities. The view never
talks to the model directly, it always goes through the controller.

Each folder is a standalone project with its own documentation.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [Sistema de Gestion de Biblioteca](./Sistema%20de%20Gestion%20de%20Biblioteca) | Books, members, and loans, with each book's status updated by the application when it's lent and returned. | C#, Windows Forms, .NET 8, EF Core, SQL Server |
