# Ejercicio Árbol

Aplicación de consola en C# que permite construir un árbol n-ario de forma
interactiva: se ingresa el nodo raíz y luego cada nodo indicando bajo qué
padre se inserta.

La estructura usa la representación **hijo-hermano**, donde cada nodo guarda
una referencia a su primer hijo y otra a su siguiente hermano. Esto permite
que un nodo tenga una cantidad arbitraria de hijos sin usar listas ni arreglos.
La búsqueda del nodo padre y los recorridos preorder y postorder están
implementados de forma recursiva, con indentación por nivel para visualizar
la jerarquía en consola.

## Requisitos Previos

Para abrir y ejecutar este proyecto en tu entorno local, necesitas tener instalado:

* .NET Framework 4.8
* Visual Studio 2022

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio en tu computadora.
2. Abre el archivo `Ejercicio Arbol.sln` en Visual Studio.
3. Presiona el botón **Iniciar** (o F5) para compilar y ejecutar la aplicación.
