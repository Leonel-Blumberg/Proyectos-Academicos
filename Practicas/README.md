# Prácticas

Tandas de ejercicios cortos agrupados por tema, hechos para practicar un
concepto puntual antes de aplicarlo en un proyecto más grande. Cada carpeta
reúne varios ejercicios que comparten la misma consigna de fondo, y cada
ejercicio es un proyecto propio dentro de la solución.

Cada carpeta es un proyecto independiente con su propia documentación.
