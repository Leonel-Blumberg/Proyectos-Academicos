# Academic Projects

Projects developed during my Systems Engineering degree at Universidad Abierta
Interamericana (UAI). Mostly C# and .NET.

Each folder is a standalone project with its own documentation.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [Aplicaciones de Escritorio](./Aplicaciones%20de%20Escritorio) | Windows Forms applications solved in a single project, with their own index. | C#, Windows Forms, .NET Framework 4.8 |
| [Aplicaciones en Capas](./Aplicaciones%20en%20Capas) | Applications split into view, controller, model, and entities, with their own index. | C#, Windows Forms, .NET Framework 4.8 |
| [CRUDS Sql Server - Dataset - EntityFramework](./CRUDS%20Sql%20Server%20-%20Dataset%20-%20EntityFramework) | Three CRUDs solving the same data access problem with different approaches. | C#, Windows Forms, SQL Server, ADO.NET, DataSet, Entity Framework Core |
| [Ejercicio con Archivos](./Ejercicio%20con%20Archivos) | Student management persisted in a text file, with search, editing, and sorted listings. | C#, .NET 8 |
| [Estructuras de Datos](./Estructuras%20de%20Datos) | Data structure exercises implemented by hand, with their own index. | C#, .NET Framework 4.8 |
| [Prácticas](./Practicas) | Batches of short exercises grouped by topic, with their own index. | C#, Windows Forms, .NET Framework 4.8 |
