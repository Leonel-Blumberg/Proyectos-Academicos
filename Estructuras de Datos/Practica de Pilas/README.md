# Práctica de Pilas

Tres ejercicios de pilas en C# con Windows Forms. La pila y el nodo están
implementados a mano, sin usar las colecciones de la biblioteca estándar, y el
recorrido para mostrar el contenido se resuelve con métodos recursivos.

Cada ejercicio es un proyecto independiente dentro de la misma solución.

## Ejercicios

**Ejercicio 1.** Contenedores apilados en un depósito, cada uno con su número de
identificación. Permite apilar, ver el tope y sacar un contenedor que quedó en
el medio. Como una pila solo da acceso al tope, hay que descargar los de arriba
en una pila auxiliar, sacar el buscado y devolver los demás en el orden
original.

**Ejercicio 2.** Recorrido de pueblos, donde el último ingresado es el destino.
Permite apilar pueblos, marcar el destino y deshacer el último tramo.

**Ejercicio 3.** Expedientes con fecha, número y carátula. Tiene las tres
operaciones básicas de una pila: apilar, desapilar y consultar el tope.

## Requisitos Previos

Para abrir y ejecutar este proyecto en tu entorno local, necesitas tener instalado:

* .NET Framework 4.8
* Visual Studio 2022

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio en tu computadora.
2. Abre el archivo `Practica de Pilas.sln` en Visual Studio.
3. Marca como proyecto de inicio el ejercicio que quieras probar y presiona el botón **Iniciar** (o F5) para compilar y ejecutar la aplicación.
