# Práctica de Nodos

Tres ejercicios de listas enlazadas simples en C# con Windows Forms. La lista y
el nodo están implementados a mano, sin usar las colecciones de la biblioteca
estándar, y el recorrido se resuelve con métodos recursivos.

Cada ejercicio es un proyecto independiente dentro de la misma solución.

## Ejercicios

**Ejercicio 1.** Lista de pacientes identificados por código, con nombres,
apellido, dirección y teléfono. Permite agregar al final, eliminar, actualizar
y agregar un paciente justo después del seleccionado.

**Ejercicio 2.** Lista de alumnos identificados por DNI, con nombre, apellido,
fecha de nacimiento, dirección y teléfono. A las operaciones del ejercicio
anterior le suma la de insertar antes del alumno seleccionado, que es el caso
que obliga a contemplar el inicio de la lista.

**Ejercicio 3.** Lista de personas que ingresan a un evento con cupo máximo. La
edad se sortea al azar y el valor de la entrada sale de ella, con precio
reducido para los menores de 18 y para los de 50 o más. Al llegar al cupo el
programa bloquea las operaciones.

## Requisitos Previos

Para abrir y ejecutar este proyecto en tu entorno local, necesitas tener instalado:

* .NET Framework 4.8
* Visual Studio 2022

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio en tu computadora.
2. Abre el archivo `Practica de Nodos.sln` en Visual Studio.
3. Marca como proyecto de inicio el ejercicio que quieras probar y presiona el botón **Iniciar** (o F5) para compilar y ejecutar la aplicación.
