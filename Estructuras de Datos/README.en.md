# Data Structures

Exercises on data structures implemented by hand, without using the .NET
standard library collections. Each structure has its own node and its own
insertion, search, and traversal operations.

Each folder is a standalone project with its own documentation.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [Ejercicio Arbol](./Ejercicio%20Arbol) | N-ary tree using child-sibling representation, with insertion, search, and preorder/postorder traversals. | C#, .NET Framework 4.8 |
