# Data Structures

Exercises on data structures implemented by hand, without using the .NET
standard library collections. Each structure has its own node and its own
insertion, search, and traversal operations.

Each folder is a standalone project with its own documentation.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [Ejercicio Arbol](./Ejercicio%20Arbol) | N-ary tree using child-sibling representation, with insertion, search, and preorder/postorder traversals. | C#, .NET Framework 4.8 |
| [Practica de Nodos](./Practica%20de%20Nodos) | Three singly linked list exercises, with add, delete, update, and insertion relative to the selected node. | C#, Windows Forms, .NET Framework 4.8 |
| [Practica de Colas](./Practica%20de%20Colas) | A queue of orders served on a first come basis, with price statistics over the ones already dispatched. | C#, Windows Forms, .NET Framework 4.8 |
| [Practica de Pilas](./Practica%20de%20Pilas) | Three stack exercises, with push, pop, peek, and pulling an item out of the middle using an auxiliary stack. | C#, Windows Forms, .NET Framework 4.8 |
