# Estructuras de Datos

Ejercicios de estructuras de datos implementadas a mano, sin usar las
colecciones de la biblioteca estándar de .NET. Cada estructura tiene su
propio nodo y sus propias operaciones de inserción, búsqueda y recorrido.

Cada carpeta es un proyecto independiente con su propia documentación.

## Proyectos

| Proyecto | Descripción | Tecnologías |
|---|---|---|
| [Ejercicio Arbol](./Ejercicio%20Arbol) | Árbol n-ario con representación hijo-hermano, inserción, búsqueda y recorridos preorder/postorder. | C#, .NET Framework 4.8 |
