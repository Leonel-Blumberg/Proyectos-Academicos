# Aplicaciones de Escritorio

Aplicaciones de escritorio en C# con Windows Forms, cada una resuelta en un
solo proyecto. Son programas completos con su propia interfaz, su validación de
datos y su lógica de negocio, sin separación en capas.

Cada carpeta es un proyecto independiente con su propia documentación.
